# モザイクブレイク — アプリUI刷新＆リアル写真5段階モザイク改修計画

Webサイトのような説明的レイアウトや子供っぽい文言を刷新し、スクロールなしの1画面で完結するスマートなゲームアプリUI、本物の写真にかけたモザイクが「100% → 70% → 40% → 10% → 0%」と純粋な粒度だけで薄れていく表現、そしてブロック崩しとして快適に遊べる広い打ち返し空間を実装します。

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 事前のヒアリングでご回答いただいた以下の3つの設計方針を反映しています。

- **Confirmed Decision 1（プレイ空間と画面設計のバランス）**: スクロールを生まない1画面完結（`100dvh`）のアプリ画面構成とし、上〜中段に「1枚の写真モザイク領域」を配置し、その下からパドルまでの間に十分な打ち返し空間（プレイヤーズゾーン）を確保します。発射直後にすぐ跳ね返る窮屈さを解消します。
- **Confirmed Decision 2（純粋なモザイク粒度表現）**: ゾーンごとの赤や青の色枠・ドットバッジ等の装飾をすべて撤廃し、純粋に写真のモザイク粒度（100% → 70% → 40% → 10% → 0%）の変化だけで削れ具合を表現します。
- **Confirmed Decision 3（実写写真素材の採用）**: 傘・自転車・やかんの3問に高画質な実写写真（Unsplashの厳選実写フリー素材、CORS対応読み込み＋通信遮断時用の写実フォールバック内蔵）を採用します。

## 1. Overview & Core Concept

- **What It Does**: モザイクのかかった1枚の実写写真に向かってボールを打ち返し、当たった箇所のモザイクを「100% → 70% → 40% → 10% → 0%（原画露出）」へと段階的にクリアにしながら、何の写真かを推理して「回答する」アーケードパズルアプリ。
- **Target Audience / Persona**: スマートフォンやPCで、直感的かつスタイリッシュに短時間で遊べる高品質なパズル＆アクションゲームを求めるプレイヤー。
- **Key Value**:
  1. **サイト感のないネイティブアプリ体験**: ページスクロールや冗長な説明カードを排し、アプリシェルの1画面内でタイトル・プレイ・回答・リザルトがシームレスに完結。
  2. **本物の写真×純粋なモザイク減衰**: 余計な枠線や記号を載せず、写真のモザイクそのものが段階的に薄れていく視覚的な気持ちよさ。
  3. **ブロック崩しとしての快適性**: 写真フレームの下に広いラリー空間を設けることで、発射直後の詰まり（「カカカカン」現象）をなくし、狙った角度へ打ち返せる本来のゲーム性を実現。

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **アプリ起動画面（タイトル）**: 1画面中央に実際の写真モザイクが変化するライブプレビューと、シンプルな「プレイ開始」ボタン・操作ガイドのみを配置。
  2. **ゲームプレイ画面**:
     - **上部ステータスバー**: ステージ表示（`STAGE 1 / 3`）、スコア、残機（ライフアイコン）、サウンド切替、ポーズを1行に集約。
     - **中央ゲームキャンバス**: 上〜中段に「モザイクがかかった1枚の写真」、下段に「十分な距離があるボール打ち返し空間＆パドル」。
     - **下部アクションバー**: パドル操作スライダーと、洗練された「回答する」ボタン（幼稚な「ひらめいた！答える」を廃止）。
  3. **回答シート（ボトムドロワー）**: 「回答する」を押すとボールが一時停止し、上の写真モザイクを見比べたまま下部で文字入力・送信が可能。
  4. **ステージクリア／リザルト**: 原画写真を100%クリアな状態で鑑賞でき、獲得スコアの内訳（残モザイク量に応じたボーナス）を確認して次のステージへ進行。

- **Visual Identity & Theme**:
  - *Aesthetic Direction*: ミニマル＆モダンなダークグラス・アプリUI（iOS/Androidのプレミアムパズルゲームのような落ち着きと没入感）。
  - *Color Palette & Mood*:
    - ベース背景: ディープチャコール（`#090D16` 〜 `#0F172A`）で写真の色彩を際立たせる額縁効果。
    - サーフェス: 半透明ダークスレート（`bg-slate-900/85 backdrop-blur-md`）と極細ボーダー（`border-white/10`）。
    - アクセント: 洗練されたインディゴブルー（`#38BDF8` / `#6366F1`）とエメラルド（`#10B981`）。
  - *Typography & Hierarchy*: 余計なバッジやピル（カプセル枠）を排し、クリーンなサンセリフ体と等幅数字（`tabular-nums`）でスコアやモザイク残量をスマートに表示。
  - *Component Styling & Layout*: `h-dvh overflow-hidden` による1画面ロック設計。PCでもスマホでもスクロールバーが出ず、画面内に美しく収まるレスポンシブ・アプリフレーム。

- **Interactive Feedback & Motion**:
  - ボールがモザイク領域にヒットした瞬間、その場所の写真カラーから抽出された微細なピクセル粒子が弾け、モザイクが1段階クリアに変化（100% → 70% → 40% → 10% → 0%）。
  - 0%になったゾーンは原画が完全に露出し、ボールがその領域を突き抜けてさらに奥のモザイクゾーンへと進入。

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: プレイフィールドの空間配分（写真領域と打ち返し空間の分離）**
  - *Chosen Approach*: キャンバス（`600×640`）の上〜中段（`y = 20 .. 340`、高さ `320px`）を写真モザイク領域とし、写真下端（`y = 340`）からパドル（`y = 584`）までの間に **`244px` の広いオープンスペース** を確保します。
  - *Why*: 従来はモザイク領域がパドル直前（残り55px）まで迫っていたため、発射直後にボールが高速往復して制御不能になっていました。十分な空間を空けることで、ボールの軌道を予測してパドルで打ち返す本来のアクション性が成立します。

- **Decision 2: 5段階の純粋なモザイク減衰（100% → 70% → 40% → 10% → 0%）**
  - *Chosen Approach*: 各ゾーンの最大耐久度を `4`（4回ヒットで完全消去）とし、ヒットごとにモザイク強度が **100%（極粗 48px）→ 70%（粗 28px）→ 40%（中 14px）→ 10%（微細 5px）→ 0%（原画 1px）** と変化する5枚のオフスクリーンCanvasレイヤーを生成します。色枠やドットは一切描画しません。
  - *Why*: 写真を撮影した後にモザイク加工を段階的に弱めていくような自然で直感的な見た目になり、今どこがどれくらい削れているかがモザイクの粗さそのもので一目瞭然になります。

- **Decision 3: 実写写真の採用と確実な描画保証**
  - *Chosen Approach*: 3つのステージ（傘・自転車・やかん）それぞれにUnsplashの高画質実写写真（`crossOrigin = "anonymous"` 指定）をプリロードして使用します。万が一オフライン環境等で画像取得に失敗した場合のみ、写実的なスタジオ写真風レンダリングへ自動フォールバックします。
  - *Why*: 実写ならではのリアルな質感・背景ボケ・色彩があることで、モザイクが70%・40%・10%と薄れていく際の「あ、これ〇〇の写真だ！」というアハ体験が劇的に高まります。

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:

```
┌─────────────────────────────────────────────────────────────────┐
│                App Shell (100dvh, overflow-hidden)              │
├─────────────────────────────────────────────────────────────────┤
│  Top App HUD Bar                                                │
│  [ STAGE 1/3 ]    [ モザイク残量 82% ]    [ ♥♥♥ · 1,240 pt · 🔊 ] │
├─────────────────────────────────────────────────────────────────┤
│  Game Viewport Canvas (600 × 640 Aspect-Fitted)                 │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │  Photo Mosaic Frame (y: 20..340, 6×5 Seamless Zones)      │  │
│  │  • Pure Pixelation: 100%(48px)→70%(28px)→40%(14px)→       │  │
│  │                     10%(5px)→0%(Original Photo)           │  │
│  │  • Zero colored borders / Zero dot badges                 │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                 │
│                 Open Rally Space (y: 340..584)                  │
│                     (244px Vertical Clearance)                  │
│                                ● Ball                           │
│                          ═════════════ Paddle                   │
├─────────────────────────────────────────────────────────────────┤
│  Bottom Control Bar / Drawer                                    │
│  [  ◀─────── パドル操作 / 発射 ───────▶  ]   [   回答する   ]     │
└─────────────────────────────────────────────────────────────────┘
```

- **Data Model & State**:
  - `MosaicStage`: ゾーンごとのモザイク強度を `hp: 4 | 3 | 2 | 1 | 0` で管理（`4 = 100%`, `3 = 70%`, `2 = 40%`, `1 = 10%`, `0 = 0%クリア`）。
  - `OffscreenMosaicPyramid`: 各ステージ開始時に実写写真から5段階（`100%`, `70%`, `40%`, `10%`, `0%`）のオフスクリーンCanvasを事前生成し、`requestAnimationFrame` ループ内では各ゾーンの `hp` に対応するレイヤーの矩形を高速転送（`drawImage`）。
  - `RealPhotoLoader`: ステージ用の実写写真を起動時に非同期プリロードし、Canvasのピクセル操作が可能な状態でキャッシュ。

- **Interactive Component & State Mapping**:
  - **Title View**: アプリ風の1画面ホーム。実写モザイクの100%→70%→40%→10%→0%変化を確認できるミニプレビューと「プレイ開始」CTA。
  - **Active Play View**: 広い下部空間でボールを打ち返し、上部の写真モザイクを削る。いつでも下部の「回答する」ボタンから回答ドロワーを開閉可能。
  - **Answer Sheet & Result View**: 「回答する」タップでボールを一時停止し、1タップ文字パネルまたはキーボードでスマートに回答送信。正解・終了時は原画写真全体とスコア内訳を表示。
